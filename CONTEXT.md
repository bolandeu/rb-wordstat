# wordstat

Частотность Яндекс.Wordstat через провайдеров (XML River, XMLStock) с фолбэком

## Словарь

**Проект**:
Каталог с `.rb_wordstat/config.toml`, созданный `wordstat init`; даёт командам настройки по умолчанию.
_Избегать_: workspace, рабочая папка

**Гейт**:
Полная проверка, которую код проходит перед коммитом и релизом: сборка, линтер, типы, тесты и контракты.
_Избегать_: CI, линт
