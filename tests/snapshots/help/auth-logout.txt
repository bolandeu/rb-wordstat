
 Usage: wordstat auth logout [OPTIONS]

 Удалить доступы провайдера из связки ключей ОС (записи serp не трогаются).

 Example: wordstat auth logout --provider xmlstock

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --provider        <str>  Провайдер. Доступны: xmlriver (XML River); xmlstock (XMLStock).         │
│                          [по умолчанию: xmlriver]                                                │
│ --json                   Машиночитаемый вывод: JSON в stdout.                                    │
│ --quiet                  Не печатать ничего, кроме данных.                                       │
│ --help                   Show this message and exit.                                             │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
