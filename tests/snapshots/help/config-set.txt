
 Usage: wordstat config set [OPTIONS] {key} {value}

 Изменить одну настройку (не секрет — ключи только через auth login).

 Example: wordstat config set providers xmlriver,xmlstock

╭─ Аргументы ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    key        <str>  Ключ настройки через точку, например providers или cli.min_version.       │
│                        [обязательный]                                                            │
│ *    value      <str>  Новое значение; для providers — список через запятую. [обязательный]      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Машиночитаемый вывод: JSON в stdout.                                            │
│ --quiet          Не печатать ничего, кроме данных.                                               │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
