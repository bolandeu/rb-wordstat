
 Usage: wordstat status [OPTIONS]

 Показать проект: имя, путь, очередь провайдеров.

 Example: wordstat status --json

│ --quiet            Не печатать ничего, кроме данных.                                             │
│ --verbose          Подробная диагностика в stderr.                                               │
│ --help             Show this message and exit.                                                   │
