
 Usage: wordstat skill install [OPTIONS]

 Скопировать памятку SKILL.md в папку навыков AI-инструмента.

 Example: wordstat skill install --tool claude-code

╭─ Параметры ──────────────────────────────────────────────────────────────────────────────────────╮
│ --tool           <str>  Для какого AI-инструмента: claude-code, agents.                          │
│                         [по умолчанию: claude-code]                                              │
│ --project               Установить в текущий проект, а не для пользователя (во все проекты).     │
│ --json                  Машиночитаемый вывод: JSON в stdout.                                     │
│ --quiet                 Не печатать ничего, кроме данных.                                        │
│ --help                  Show this message and exit.                                              │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
